# 勇者の冒険 REAL v7.1 3D

操作改善版です。

## スマホ操作
- 左スティック: キャラクター移動
- 画面の空いている場所をドラッグ: カメラ回転
- 上下ドラッグ: カメラの上下角度
- 左右ドラッグ: カメラを左右回転
- 画面をダブルタップ: カメラをプレイヤー背後へ戻す
- 右側ボタン: 攻撃 / スキル / 回避 / 防御 / 回復 / 必殺

v7の人型キャラ、敵モデル、町、NPC、クエスト、昼夜、天候などは維持しています。
