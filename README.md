# 勇者の冒険 REAL v6 3D

Three.jsを使った本格3D版です。

主な機能:
- 第三者視点3Dカメラ
- 3D地形
- 森・岩・遺跡・城
- 3Dプレイヤー
- スマホ用仮想スティック
- リアルタイム戦闘
- スタミナ
- 回避
- ガード
- スキル
- 必殺技
- 敵AI
- 仲間AI
- 巨大ボス3体
- ボス第2形態
- ジャスト回避
- ミニマップ
- セーブ/ロード
